セバスチャン プライバシーポリシー

最終更新日: 2026年7月23日

「セバスチャン」（以下「本アプリ」）は、話しかけるだけで予定やリマインダーを登録できるAI執事アプリです。 本アプリの開発・運営者（以下「運営」）は、ユーザーのプライバシーを最大限に尊重します。 本アプリは、アカウント登録・ログインを一切必要とせず、氏名・連絡先・位置情報などの個人情報を収集しません。 文章の解析方法は端末により異なり、Apple Intelligence 対応端末では端末内で完結し、非対応端末では 下記のとおりクラウドのAIサービス（無料枠は Google Gemini、任意の月額サブスク「セバスちゃん Pro」会員は Anthropic Claude）を利用します。以下で具体的に説明します。

1. 収集しない情報

本アプリは、次のような情報を収集・外部送信・保存しません。

  • 氏名・メールアドレス・電話番号などの個人情報（アカウント登録・ログインの仕組みそのものがありません）
  • 位置情報
  • 連絡先・写真・その他の端末内データ
  • 利用状況・診断データ・広告識別子などのトラッキング情報

2. 文章の解析方法（端末により異なります）

ユーザーがチャットに入力した文章の解析（予定名・日時・通知の読み取り）は、お使いの端末の対応状況に応じて 次の2通りのいずれかで行われます。

  • Apple Intelligence 対応端末（完全オンデバイス）: 解析はすべて端末内のApple Intelligence（Foundation Models）で処理されます。 入力した文章や解析結果がインターネットを通じて運営や第三者に送信されることは一切ありません。
  • Apple Intelligence 非対応端末（クラウド解析）: 端末内AIが使えないため、入力した文章のみを、運営が管理する中継サーバー（Supabase）を経由して、 無料枠はGoogle のAIサービス「Gemini API」へ、「セバスちゃん Pro」会員は Anthropic のAIサービス「Claude API」へ送信し、解析結果を受け取ります（下記 第3項）。

3. クラウド解析（Google Gemini / Anthropic Claude）について

Apple Intelligence 非対応端末でチャット解析を行う場合、入力した文章がGoogleまたはAnthropicのサーバーへ送信されます （無料枠はGoogle Gemini、「セバスちゃん Pro」会員はAnthropic Claude）。この点は完全オンデバイス処理とは異なるため、以下を明示します。

  • 送信されるのは解析対象の入力文のみです。氏名・連絡先・カレンダーの中身・位置情報などは送信しません。
  • Googleの無料枠（Gemini API 無料利用枠）の利用規約上、送信された内容がGoogleのサービス・モデルの改善に利用される場合があります。機微な情報の入力はお控えください。Googleの取り扱いは Gemini API 追加利用規約 および Googleプライバシーポリシー に従います。
  • Anthropic（Claude API）は、APIを通じて送信された内容をモデルの学習には使用しません（Anthropicのプライバシーポリシー参照）。
  • 無料枠の範囲内で提供するため、利用回数の管理のみを目的として、端末ごとに割り当てた匿名のランダムIDを中継サーバーで用います。このIDから個人を特定することはできません。
  • 入力文の中継以外の目的で、運営が文章の内容を保存・分析・第三者提供することはありません。
  • クラウド解析を使いたくない場合は、チャットを使わず画面の「＋」ボタンから予定を手動で入力できます（この場合、文章が外部へ送信されることはありません）。

4. カレンダー・リマインダーへのアクセスについて

本アプリは、ユーザーが承認した予定・リマインダーを登録・編集・閲覧するために、iOS標準の カレンダー / リマインダー（EventKit）へのアクセス許可を求めます。

  • これらのデータは、お使いの端末およびユーザー自身のiCloud（Appleのアカウント）内にのみ保存されます。
  • 本アプリの運営がこれらのデータを閲覧・取得・外部送信することはできません。
  • 予定・リマインダーの登録は、必ずユーザーが確認カードで内容を確認し、承認したときにのみ行われます。
  • アクセス許可はいつでもiOSの「設定」アプリから変更・取り消しできます。

5. 第三者提供・広告

本アプリは広告SDK・トラッキングSDKの類を一切組み込んでいません。ユーザーのデータを広告・マーケティング目的で第三者に提供することはありません。 Apple Intelligence 非対応端末でのチャット解析にあたり、入力文の解析を目的として Google（Gemini API）へ入力文を送信する点のみ、第2項・第3項に記載のとおりです。

サービス内容

本アプリ「セバスチャン」は、ユーザーが入力した自由文を端末内のAIで解析し、確認のうえ iOSのカレンダー・リマインダーに予定を登録・編集できる実用ツールです。手動で予定・リマインダーを入力・編集することもできます。
