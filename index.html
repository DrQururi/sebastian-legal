1. 収集しない情報

本アプリは、次のような情報を収集・外部送信・保存しません。

  • 氏名・メールアドレス・電話番号などの個人情報（アカウント登録・ログインの仕組みそのものがありません）
  • 位置情報
  • 連絡先・写真ライブラリ・その他の端末内データ（「画像から予定を読み取る」であなたが選んだ画像だけは、端末内で文字に変換するために一時的に読み込みます。画像は保存せず、画像そのものは送信しません。第2-2項）

  • 広告識別子（IDFA）や、他社のアプリ・Webサイトを横断してユーザーを追跡（トラッキング）するための情報

※ 送信するものは2つだけです。①チャット解析のためにあなたが入力した文章、または画像から端末内で読み取った文字（同意後のみ・第2項/第2-2項/第3項）と、 ②アプリ改善のための匿名の利用統計（第3-3項）です。

2. 文章の解析方法

ユーザーがチャットに入力した文章の解析（予定名・日時・通知の読み取り）は、お使いの端末・会員/非会員の 区別なく、次のいずれかで行われます。

  • クラウド解析（全端末・会員/非会員 共通）: 入力した文章（画像取り込みの場合は、画像から端末内で読み取った文字）のみを、運営が管理する中継サーバー（Supabase）を経由してクラウドのAIサービスへ送信し、解析結果を受け取ります（下記 第3項）。 送信先はアプリのバージョンによって異なります。 バージョン1.9.3 以降は Anthropic 社の「Claude」のみへ送信し、Google へは送信しません。 バージョン1.9.2 以前は Google のAIサービス「Gemini API」へ送信します。 「セバスちゃん Pro」会員は解析できる回数が多くなりますが、使用するAIサービスは非会員と同じです。
    ※ 以前のバージョンでは端末内解析や、Pro会員のみ別のAIサービスへ送信する仕組みを使っていました。2026年9月30日以降は1.9.2 以前のすべての端末・会員種別で Google Gemini に統一し、1.9.3 以降は Anthropic（Claude）に変更しています。
  • 解析を使わない場合: 上記の送信に同意しない場合や通信できない場合も、 手動での予定・リマインダーの追加・編集で本アプリの全機能をご利用いただけます。

2-2. 画像から予定を読み取る機能（端末内で文字化・画像は送りません）

チャット画面の画像ボタンから、写真・スクリーンショット・ファイルの画像（1回に最大3枚）を選ぶと、画像に写っている予定を読み取って候補として表示します。

  • 画像から文字への変換は端末内（Appleの文字認識機能）で行います。画像そのものは運営にもGoogleにもAnthropicにも送信せず、保存もしません（チャット画面の表示用に、小さなサムネイルをメモリ上に一時的に保持するだけです）。
  • 送信されるのは、画像から端末内で読み取った文字だけです。第3項のクラウド解析（1.9.3 以降は Anthropic、1.9.2 以前は Google）と同じ送信先・同じ同意が必要で、同意前や同意を取り消した後は何も送信されません。すでに同意済みの方には、画像取り込みを初めて使うときに1回だけ確認画面を表示します。
  • 写真の選択にはiOS標準の写真ピッカーを使うため、写真ライブラリ全体へのアクセス許可は求めません。選んだ画像だけを読み込みます。「ファイルから選ぶ」「クリップボードの画像を使う」「ドラッグ&ドロップ」も、あなたが操作して選んだ画像だけが対象です。
  • 1回に送信する文字数には上限（6,000文字）があり、超えた分は送信されません。
  • 画像に他の方のお名前などが写っている場合、その文字も読み取り結果に含まれ、送信されることがあります。他の方の情報が写った画像の取り扱いにはご注意ください。

3. クラウド解析（Anthropic Claude／Google Gemini）について

チャット解析を行う場合、お使いの端末の種類・会員/非会員を問わず、入力した文章（画像取り込みの場合は、画像から端末内で読み取った文字）が外部のAIサービスのサーバーへ送信されます。 端末内だけで完結する処理ではないため、以下を明示します。

  • 送信先はバージョンによって異なります。 1.9.3 以降：Anthropic 社の「Claude」のみ（Google へは送信しません）。 1.9.2 以前：Google の「Gemini API」。 1.9.3 では、AI解析の送信先を Google（Gemini）から Anthropic（Claude）に変更しました。
  • 送信前にアプリ内で同意をいただきます。クラウド解析が初めて必要になったとき、アプリ内の確認画面で「何を送信するか（入力した文章、または画像から端末内で読み取った文字のみ。画像そのものは送信しません）」「どこへ送信するか（1.9.3 以降は Anthropic の Claude）」を明示し、あなたの同意を得てから送信します。同意するまで、入力文が外部へ送信されることは一切ありません。 1.9.2 以前でAI解析に同意済みの方も、1.9.3 に更新したあと最初にAI解析を使うときに、新しい送信先についてあらためて同意をお願いします。同意しない場合は何も送信されず、チャットのAI解析は使えませんが、手動での予定追加・編集を含むその他の機能はそのままご利用いただけます。 同意はアプリの設定からいつでも取り消せます（1.9.3 以降は「設定 > AI解析（Claude）」、1.9.2 以前は「設定 > AI解析（Google Gemini）」。取り消し後は一切送信されません）。
  • 送信されるのは解析対象の入力文（画像取り込みの場合は、画像から端末内で読み取った文字）のみです。画像そのものは送信しません。アプリが端末から集める氏名・連絡先・カレンダーの中身・位置情報などは送信しません。なお、画像に写っている文字（他の方のお名前など）は、予定を読み取る目的で文字として送信されることがあります。

  • 【1.9.2 以前：Google（Gemini）】解析の多くはGoogleの無料枠（Gemini API 無料利用枠）で処理されます。無料枠の利用規約上、送信された内容がGoogleのサービス・モデルの改善に利用される場合があります。機微な情報の入力はお控えください。無料枠が混雑・上限に達した場合、運営が用意した従量課金の予備キーで継続することがありますが、送信先・送信内容・目的は変わりません。Googleの取り扱いは Gemini API 追加利用規約 および Googleプライバシーポリシー に従います。

  • クラウド解析を使いたくない場合は、同意画面で「今は使わない」を選ぶか、アプリの設定（1.9.3 以降は「AI解析（Claude）」）でオフにしてください。チャットを使わず画面の「＋」ボタンから予定を手動で入力でき、すべての機能をご利用いただけます（この場合、文章が外部へ送信されることはありません）。

3-2. 解析の改善への協力（任意・既定オフ）

本アプリには、解析の精度を全ユーザーで少しずつ高めるための任意の協力機能があります。 アプリの設定（1.9.3 以降は「AI解析（Claude）」、1.9.2 以前は「AI解析（Google Gemini）」）内のトグル「解析の改善に協力する」で、あなたが明示的にオンにした場合にのみ有効になります。既定はオフで、オフの間はこの機能で送信されるものは一切ありません。

  • 何を送るか：AIの解析結果をあなたが修正して登録したとき、その「入力した文章（画像取り込みの場合は、読み取った文字）」「AIの解析結果（修正前）」「あなたが確定した正しい内容（修正後）」の3点のみを送信します。AIが最初から正しく、あなたが修正しなかった場合は何も送信しません。
  • 匿名であること：氏名・連絡先・位置情報・端末IDそのものは送信しません。粗い集計のために端末IDを復元不可能な一方向ハッシュへ変換した値のみを用い、個人を特定することはできません。
  • 使いみち：集めた修正例は、次回以降の解析で「似た入力での正しい例」や「誤りを一般化した注意点」としてAIに参照させ、同じ間違いを繰り返さないための精度向上にのみ利用します。1.9.2 以前では、送信先は解析と同じく Google（Gemini API）です。1.9.3 以降では、修正例は運営のサーバーに匿名で保存し、Google へは送信しません（1.9.3 では、この協力機能もあらためてオンにするかを確認し、既定はオフです）。
  • いつでも停止できます：同じトグルをオフにすれば、以降は送信されません。

3-3. 匿名の利用統計（アプリ改善のため）

本アプリは、どの機能がどれだけ使われているかを把握してアプリを改善するために、以下の匿名データを 運営が管理するサーバー（Supabase）へ送信します。上記のAI解析とは別の仕組みで、外部のAIサービスへは送りません。

  • イベント名（アプリの起動、予定の登録 など）と発生日時
  • 1回の利用時間（セッション長）・起動した時間帯
  • アプリのバージョン・iOSのバージョン
  • 匿名インストールID（初回起動時に生成するランダムな文字列。氏名・メールアドレス・端末IDや広告IDとは一切結び付いておらず、アプリを削除・再インストールすると別の値になります）

あなたが入力した文章・画像から読み取った文字・予定やリマインダーの中身・日時・位置情報は含みません。 また、他社のアプリやWebサイトを横断してユーザーを追跡（トラッキング）することは一切なく、広告IDも使用していません。

この送信はアプリ内でいつでも停止できます（「設定 > 利用状況の送信」の「匿名の利用統計を送信」をオフ）。 オフにすると、以後は一切送信されず、まだ送信していない分も破棄されます。

3-4. 予定の共有（任意機能）

共有タブを開くと、サインインやメールアドレスの入力なしで使える専用のアカウントを端末ごとに 自動で作成します（お名前・メールアドレスの入力は不要です）。

グループに参加・作成すると、以下の情報を当社が管理するサーバー（Supabase）に保存します。

  • グループに参加する際に入力した表示名（任意のニックネームで構いません）
  • 自分で選んだカレンダーの予定のうち、開始・終了時刻、終日かどうか、予定名（または「見せ方」で 「予定ありだけ」を選んだ場合は予定名を送らず「予定あり」の情報のみ）
  • 予定の色
  • 上記を端末ごとに識別するための、匿名のアカウントID

保存した情報は、同じグループに参加しているメンバーにのみ表示されます。場所・メモ・参加者情報は 送信しません。個別の予定には「この予定は共有しない」を設定でき、その予定は送信されません。

共有タブを一度も開かない場合、この機能によるデータの送信は一切発生しません。

データの削除は、いつでも次の方法で行えます。

  • 設定 ＞ その他 ＞「共有のアカウントを削除」から、参加している全グループを退出し、 サーバーに保存した自分の予定・表示名をすべて削除する
  • 特定のグループだけをやめたい場合は、そのグループの設定画面から「退出」する

退出・削除すると、そのグループの他のメンバーの表からも自分の予定は消えます。

4. カレンダー・リマインダーへのアクセスについて

本アプリは、ユーザーが承認した予定・リマインダーを登録・編集・閲覧するために、iOS標準の カレンダー / リマインダー（EventKit）へのアクセス許可を求めます。

  • これらのデータは、お使いの端末およびユーザー自身のiCloud（Appleのアカウント）内にのみ保存されます。
  • 本アプリの運営がこれらのデータを閲覧・取得・外部送信することはできません。
  • 予定・リマインダーの登録は、必ずユーザーが確認カードで内容を確認し、承認したときにのみ行われます。
  • アクセス許可はいつでもiOSの「設定」アプリから変更・取り消しできます。
