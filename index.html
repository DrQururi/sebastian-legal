「セバスチャン」（以下「本アプリ」）は、話しかけるだけで予定やリマインダーを登録できるAI執事アプリです。 本アプリの開発・運営者（以下「運営」）は、ユーザーのプライバシーを最大限に尊重します。 本アプリは、アカウント登録・ログインを一切必要とせず、氏名・連絡先・位置情報などの個人情報を収集しません。 文章の解析は、端末の種類・会員/非会員を問わず、下記のとおりクラウドのAIサービス「Google Gemini」を利用して行います。 送信前にアプリ内で同意をいただき、同意いただくまで一切送信しません。 このほかに、アプリ改善のための匿名の利用統計を運営のサーバーへ送信します（設定でオフにできます。詳細は「3-3. 匿名の利用統計」）。以下で具体的に説明します。

1. 収集しない情報

本アプリは、次のような情報を収集・外部送信・保存しません。

  • 氏名・メールアドレス・電話番号などの個人情報（アカウント登録・ログインの仕組みそのものがありません）
  • 位置情報
  • 連絡先・写真・その他の端末内データ
  • カレンダー・リマインダーに登録されている予定の中身（第4項）
  • 広告識別子（IDFA）や、他社のアプリ・Webサイトを横断してユーザーを追跡（トラッキング）するための情報

※ 送信するものは2つだけです。①チャット解析のためにあなたが入力した文章（同意後のみ・第2項/第3項）と、 ②アプリ改善のための匿名の利用統計（第3-3項）です。

2. 文章の解析方法

ユーザーがチャットに入力した文章の解析（予定名・日時・通知の読み取り）は、お使いの端末・会員/非会員の 区別なく、次のいずれかで行われます。

  • クラウド解析（全端末・会員/非会員 共通）: 入力した文章のみを、運営が管理する中継サーバー（Supabase）を経由して Google のAIサービス「Gemini API」へ送信し、解析結果を受け取ります（下記 第3項）。 多くのリクエストは無料枠で処理され、無料枠が混雑・上限に達した場合に限り、 運営が用意した従量課金の予備キーで継続することがあります（送信先・送信内容・取り扱いはいずれも同じです）。 「セバスちゃん Pro」会員は1日に解析できる回数が多くなりますが、使用するAIサービスは非会員と同じ Gemini です。
    ※ 以前のバージョンでは端末内解析や、Pro会員のみ別のAIサービスへ送信する仕組みを使っていましたが、 解析精度を揃えるため、2026年9月30日以降はすべての端末・会員種別で Google Gemini に統一しています。
  • 解析を使わない場合: 上記の送信に同意しない場合や通信できない場合も、 手動での予定・リマインダーの追加・編集で本アプリの全機能をご利用いただけます。

3. クラウド解析（Google Gemini）について

チャット解析を行う場合、お使いの端末の種類・会員/非会員を問わず、入力した文章がGoogleのサーバーへ送信されます。 端末内だけで完結する処理ではないため、以下を明示します。

  • 送信前にアプリ内で同意をいただきます。クラウド解析が初めて必要になったとき、アプリ内の確認画面で「何を送信するか（入力した文章のみ）」「どこへ送信するか（Google Gemini API）」を明示し、あなたの同意を得てから送信します。同意するまで、入力文が外部へ送信されることは一切ありません。同意はアプリの「設定 > 外部AI解析（クラウド）」からいつでも取り消せます（取り消し後は一切送信されません）。
  • 送信されるのは解析対象の入力文のみです。氏名・連絡先・カレンダーの中身・位置情報などは送信しません。
  • 解析の多くはGoogleの無料枠（Gemini API 無料利用枠）で処理されます。無料枠の利用規約上、送信された内容がGoogleのサービス・モデルの改善に利用される場合があります。機微な情報の入力はお控えください。無料枠が混雑・上限に達した場合、運営が用意した従量課金の予備キーで継続することがありますが、送信先・送信内容・目的は変わりません。Googleの取り扱いは Gemini API 追加利用規約 および Googleプライバシーポリシー に従います。
  • 「セバスちゃん Pro」会員も同じ Google Gemini API へ送信されます。会員は1日に解析できる回数が非会員より多くなりますが、送信する内容・送信先・取り扱いはすべて非会員と同じです。
  • 無料枠の範囲内で提供するため、利用回数の管理のみを目的として、端末ごとに割り当てた匿名のランダムIDを中継サーバーで用います。このIDから個人を特定することはできません。
  • 入力文の中継以外の目的で、運営が文章の内容を保存・分析・第三者提供することはありません。
  • クラウド解析を使いたくない場合は、同意画面で「今は使わない」を選ぶか、アプリの「設定 > 外部AI解析（クラウド）」でオフにしてください。チャットを使わず画面の「＋」ボタンから予定を手動で入力でき、すべての機能をご利用いただけます（この場合、文章が外部へ送信されることはありません）。

3-2. 解析の改善への協力（任意・既定オフ）

本アプリには、解析の精度を全ユーザーで少しずつ高めるための任意の協力機能があります。 アプリの「設定 > 外部AI解析（クラウド）」内のトグル「解析の改善に協力する」で、あなたが明示的にオンにした場合にのみ有効になります。既定はオフで、オフの間はこの機能で送信されるものは一切ありません。

  • 何を送るか：AIの解析結果をあなたが修正して登録したとき、その「入力した文章」「AIの解析結果（修正前）」「あなたが確定した正しい内容（修正後）」の3点のみを送信します。AIが最初から正しく、あなたが修正しなかった場合は何も送信しません。
  • 匿名であること：氏名・連絡先・位置情報・端末IDそのものは送信しません。粗い集計のために端末IDを復元不可能な一方向ハッシュへ変換した値のみを用い、個人を特定することはできません。
  • 使いみち：集めた修正例は、次回以降の解析で「似た入力での正しい例」や「誤りを一般化した注意点」としてAIに参照させ、同じ間違いを繰り返さないための精度向上にのみ利用します。送信先は解析と同じく Google（Gemini API）です。
  • いつでも停止できます：同じトグルをオフにすれば、以降は送信されません。

3-3. 匿名の利用統計（アプリ改善のため）

本アプリは、どの機能がどれだけ使われているかを把握してアプリを改善するために、以下の匿名データを 運営が管理するサーバー（Supabase）へ送信します。上記のAI解析とは別の仕組みで、外部のAIサービスへは送りません。

  • イベント名（アプリの起動、予定の登録 など）と発生日時
  • 1回の利用時間（セッション長）・起動した時間帯
  • アプリのバージョン・iOSのバージョン
  • 匿名インストールID（初回起動時に生成するランダムな文字列。氏名・メールアドレス・端末IDや広告IDとは一切結び付いておらず、アプリを削除・再インストールすると別の値になります）

あなたが入力した文章・予定やリマインダーの中身・日時・位置情報は含みません。 また、他社のアプリやWebサイトを横断してユーザーを追跡（トラッキング）することは一切なく、広告IDも使用していません。

この送信はアプリ内でいつでも停止できます（「設定 > 利用状況の送信」の「匿名の利用統計を送信」をオフ）。 オフにすると、以後は一切送信されず、まだ送信していない分も破棄されます。

4. カレンダー・リマインダーへのアクセスについて

本アプリは、ユーザーが承認した予定・リマインダーを登録・編集・閲覧するために、iOS標準の カレンダー / リマインダー（EventKit）へのアクセス許可を求めます。

  • これらのデータは、お使いの端末およびユーザー自身のiCloud（Appleのアカウント）内にのみ保存されます。
  • 本アプリの運営がこれらのデータを閲覧・取得・外部送信することはできません。
  • 予定・リマインダーの登録は、必ずユーザーが確認カードで内容を確認し、承認したときにのみ行われます。
  • アクセス許可はいつでもiOSの「設定」アプリから変更・取り消しできます。

5. 第三者提供・広告

本アプリは広告SDK・第三者のトラッキングSDKの類を一切組み込んでいません。ユーザーのデータを広告・マーケティング目的で第三者に提供することはありません。 外部への送信は次の2つに限られます。①チャット解析にあたり、アプリ内で同意をいただいたうえで、入力文の解析のみを目的として Google（Gemini API）へ入力文を送信すること（第2項・第3項）。 ②アプリ改善のための匿名の利用統計を、運営自身が管理するサーバーへ送信すること（第3-3項。第三者への提供ではありません）。
